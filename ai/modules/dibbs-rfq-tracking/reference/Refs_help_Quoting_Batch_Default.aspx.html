Batch Quoting

Batch quoting allows multiple quotes on Request for Quotations (RFQ) to be batch uploaded.  Quotes are prepared off-line in a prescribed comma delimited format then uploaded via the Internet.
BatchNotes
· Batch File Format
Batch File Format link contians the formatting requirements and acceptable values for batch quoting.

· Batch File Size Limit
Files are limited to 75 lines per file.   Files with more lines will not be processed.   The size of the file has a great effect on the validating process performance.   The smaller the file,the faster the validation.

· Preformated RFQ Batch Files
Preformated RFQ Batch Files are available at Recent RFQs under the heading "Batch Quote File Name".
