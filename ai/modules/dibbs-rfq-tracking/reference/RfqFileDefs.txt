Downloadable RFQ Files
Files are located here .
Software Needed
A compression utility is required to open the "ZIP" files.
A text viewer such as notepad is required for viewing text ".txt" files.
Adobe® Acrobat Reader is required for viewing any "PDF" documents
contained in the "ZIP" file.
See
Document Viewers
for links to compression tools and viewing software.
File Description
Contains All or "ca" compressed file.
This compressed file contains all Request For Quote (RFQ) solicitation documents
posted for the indicated date. The file name format begins with "ca" followed
by the two-digit year, month and day and ending with ".zip". Example:
ca070427.zip Links to these files are located in the "Zip File Name" column
on the Recent RFQ Page.
Index Text or "in" file.
This text file contains a fixed format listing of all Request For Quote (RFQ) solicitations
posted for the indicated date. The file name format begins with "in" followed
by the two digit year, month and day and ending with ".txt". example:
in070427.txt Links to these files are located in the "Index File Name"
column on the Recent RFQ Page.

Batch Quote or "bq" compressed file.
This compressed file contains two text files that are used for batch quoting. Data
contained in these files are also useful for any other off-line evaluation routines.
Links to these files are located in the "Batch Quote File Name" column
on the Recent RFQ Page.
1. Batch Quote text file contains preformatted, comma delimited, double quote separated
data for Request For Quote (RFQ) solicitations posted for the indicated date. The
file name format begins with "bq" followed by the two-digit year, month
and day and ending with ".txt". Example: bq070427.txt A description of
the file layout and validation requirements are in the DIBBS Batch quoting help
located here
2. Approved Source text file containing a preformatted, comma delimited, double
quote separated approved sources for Request For Quote (RFQ) solicitations contained
in the associated "bq" file. The file name format begins with "as"
followed by the two-digit year, month and day and ending with ".txt".
Example: as070427.txt
File layout:
NSN, Approve Source CAGE, Part Number, Approved Source Company Name
Data Example:
"6640014392807","08071","XX63 1K1 15","MILLIPORE
CORPORATION"
Batch Quote Other or "bqothers" compressed file.
This compressed file contains all other available RFQ solicitations in Batch Quote
File Format that are not contained to the date specific files. This file link is
located at the bottom of Recent RFQ Page. The description contain the file layout
and validation requirements are located in the DIBBS Batch quoting help located
here
Updates
Posting of new files occur daily. Posting of links to the current day
files will not display until the next day because file updates occur through out
the day.
Download Preparation
Prior to downloading files, we recommend creating a storage location
on your computer.
Downloading Files
1. Locate your desired file and click on the file name.
2. Depending on your browser and PC configuration, a prompted to open
or save the file may occur. Consult your software help instructions for any needed
assistance. Note: Help is available for most Windows based software by pressing
the "F1" key.
